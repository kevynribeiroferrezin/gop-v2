# Manual do Usuário

## Login

1. Acesse `/login`.
2. Informe e-mail e senha.
3. Clique em `Entrar`.

Se esquecer a senha, use `Esqueceu a senha?`. O sistema envia um link para redefinição.

## Dashboard

O dashboard mostra:

- Presentes hoje.
- Faltas hoje.
- Atrasos hoje.
- Colaboradores ativos.
- Resumo do dia.
- Chamadas pendentes.

A data do sistema usa o fuso `America/Sao_Paulo`.

## Chamada

A tela de chamada é usada por admin e supervisor.

1. Acesse `Chamada`.
2. Confira a data da chamada.
3. Selecione o supervisor.
4. Marque os colaboradores que não estão como presença normal.
5. Use `Salvar alterações`.
6. Use `Finalizar chamada` quando tudo estiver conferido.

Status disponíveis:

- Presente.
- Falta.
- Atraso.
- Atestado.
- Folga.
- Férias.
- Afastado.

## Férias

1. Na chamada, clique em `Férias`.
2. Informe data inicial e final.
3. Confirme o lançamento.

O sistema grava férias dia a dia para manter a consulta por data.

## Colaboradores

Na tela `Colaboradores`, usuários autorizados podem:

- Buscar por nome, matrícula, cargo ou supervisor.
- Criar colaborador.
- Editar cadastro.
- Ativar ou inativar colaborador.

Campos principais:

- Matrícula.
- Nome completo.
- Cargo.
- Supervisor.
- Regional.
- Data de admissão.
- Status.
- Observação.

## Acesso Negado

Se o usuário tentar acessar uma tela fora do seu perfil, será redirecionado para `/acesso-negado`.
